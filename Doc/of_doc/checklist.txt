## [艺术家自查清单 / 通用自查] 通用自查

分类: 艺术家自查清单 / 通用自查
分类ID: checklist
卡片ID: chk-general
Confluence PID: checklist
来源锚点: #chk-general

- 是否对照客户参考逐项检查（参考片/概念图/Key Art），不做参考里没有的、不遗漏参考里有的
- 是否理解了镜头在整场戏中的叙事目的——特效是推进剧情还是烘托氛围
- 技术规格确认：分辨率、帧率（24/25fps）、色彩空间（ACES/sRGB）、Cut 帧范围、交付格式
- 元素的大/中/小比例是否合理——前景细节、中景主体、远景氛围层次分明
- 视觉重心是否在正确位置，是否有意外抢戏的元素分散注意力
- 运动模糊是否正确——Houdini 中有正确的 velocity 属性，Maya/Arnold 中 velocity 或 shutter 设置正确
- 是否遵循「粗动态 → 细节 → 灯光合成」的分步法，而不是一次性全做完
- 文件命名是否符合规范：场次_镜头_任务_v版本号
- Daily 是否按时上传（11:30 / 17:30），命名正确（seq###_shot###_sfx_*_v###.mov）
- 是否清理了无用节点、缓存和参考文件，工程文件整洁可交付

## [艺术家自查清单 / 魔法与能量特效] 魔法与能量特效

分类: 艺术家自查清单 / 魔法与能量特效
分类ID: checklist
卡片ID: chk-magic
Confluence PID: checklist
来源锚点: #chk-magic

- 魔法拉丝粒子
- 粒子出生位置是否精确跟随源物体表面或边缘（角色手指/武器/魔法阵）
- 拉丝（Trail）的长度、粗细、透明度衰减是否符合参考——丝的头部密集、尾部稀疏消散
- 粒子的运动是否受噪声场驱动——使用 Curl Noise 或 Turbulence 避免直线运动
- 粒子颜色是否沿生命周期变化——出生时高亮/高饱和，死亡时暗/低饱和消散
- 辉光（Glow）是否正确——核心白亮 + 外层颜色扩散 + 最外层柔光衰减
- 丝的缠绕和交错是否自然——多条丝之间是否有速度差和相位差，避免同步平行运动
- 粒子在停滞或转弯时是否有堆积/聚集效果——速度=0 时粒子应聚集发光而非消失
- 是否有二级粒子——拉丝周围散落的小光点/火星（Sparks）增加层次感
- 是否有拖尾的消散动画——粒子/丝不会突然消失，而是逐渐透明+缩小直至消失
- 魔法蔓延
- 蔓延的方向和路径是否符合设定——沿地面/墙面纹理扩散，还是沿魔法符文线条传播
- 蔓延的前沿（Leading Edge）是否最亮最活跃——能量在扩展边缘集中，后方渐弱
- 是否有正确的蔓延节奏——初始慢（蓄力）、加速扩展、减速定型，曲线呈 S 形
- 蔓延是否根据表面法线/曲率变化——沿凹凸表面爬升时速度应变化，不应浮在表面上方
- 蔓延的分支（Branching）是否自然——分叉角度、分支粗细渐变是否类似闪电/树根/裂纹
- 蔓延到达边界时是否有正确的终止行为——回弹（Bounce）/消散（Dissipate）/反射
- 不同蔓延源相遇时是否有交互——能量碰撞/抵消/融合，而非简单穿透
- 刀光 / 斩击轨迹
- 刀光的起止帧是否与武器运动精确匹配——从挥砍起始到结束，不允许错帧
- 刀光的形状是否与武器类型匹配——细剑（细长弧线）、重剑（宽厚月牙）、匕首（短促直线）
- 刀光的颜色是否与武器/角色属性一致（火焰=橙红、冰霜=蓝白、暗影=紫黑、神圣=金白）
- 是否有正确的拖尾（Trail）——刀光主体后有渐隐的能量尾迹，而非突然截断
- 刀光的核心（Core）最亮最窄、辉光层（Glow）扩散柔和，两层叠加
- 多段斩击（Combo）的刀光之间是否衔接——前一道光残留消散时后一道光出现
- 刀光与场景的交互——应该照亮附近的地面/墙壁/角色
- 刀光击中目标时的反馈——命中瞬间高亮+粒子迸发+被击中物体的反应
- 能量吸收
- 能量吸收的方向是否正确——从外向内汇聚（Implode），还是从指定方向吸入
- 被吸收的能量粒子是否有正确的运动轨迹——螺旋向内旋转加速，类似漩涡/黑洞效果
- 吸收核心（Core）是否随着能量聚集而变亮/变大——能量密度增加，核心逐渐饱和
- 是否有能量流入的拖尾/流线——能量沿流线（Streamline）被吸向中心
- 吸收过程中源物体（被吸能的一方）是否有视觉变化——颜色变暗/饱和度降低/变透明
- 吸收完成后是否有释放/稳定态的过渡——能量储存完成后的光晕/脉动/呼吸效果
- 周围环境是否受吸收影响——附近粒子/尘土被拉向吸收点，灯光被吸暗
- 魔法烟雾
- 魔法烟雾的颜色是否与魔法属性匹配——火=橙红黑烟，冰=白蓝冷烟，毒=绿紫烟，暗影=黑紫烟
- 烟雾的发射源是否正确——从魔法阵/角色/武器/地面裂缝中涌出
- 是否有彩色辉光穿透烟雾——高能量烟雾内部发光（Emission），不仅是表面颜色
- 烟雾的流动是否有方向性——不应是漫无目的的扩散，应有明确流动路径
- 烟雾中是否混合了粒子/火星——魔法烟雾通常伴随发光粒子悬浮其中
- 烟雾的消散是否区分于普通烟雾——魔法烟消散时可能有粒子散开/光点飘落/颜色残留
- 不同魔法源的烟雾相遇时是否有反应——融合/排斥/颜色混合

## [艺术家自查清单 / 破碎与爆炸] 破碎与爆炸

分类: 艺术家自查清单 / 破碎与爆炸
分类ID: checklist
卡片ID: chk-destruction
Confluence PID: checklist
来源锚点: #chk-destruction

- 破碎
- 破碎的力源分析是否正确——冲击点位置、力的方向和大小、衰减半径
- 破碎是否分层——主断裂（大块）、次级断裂（中块）、表面碎裂（细碎），每层使用不同约束强度
- 断裂模式是否符合材质——混凝土（不规则块状+粉尘）、木头（顺纹撕裂+碎片）、玻璃（锐利三角+飞溅）、金属（弯曲变形+少碎片）
- 是否有正确的约束网络（Constraint Network）——不同区域断裂阈值不同
- 大块碎片落地后的二次破碎（Secondary Fracture）是否到位
- 碎块是否有正确的 UV——截面 UV（新断裂面）和表面 UV 区分摆放
- 是否有 velocity 属性——碎块运动模糊、碎片飞溅方向正确
- 是否有粉尘/烟雾伴随——断裂瞬间的冲击粉尘，大块落地时的扬尘
- 碎块的碰撞检测是否准确——不应穿入地面或其他碰撞体
- 模拟结束后静态碎块是否有 Settling——碎片落地后不应漂浮
- 爆炸
- 爆炸的时间线是否完整——冲击波帧（1-2帧）→ 火球膨胀 → 烟雾上升 → 余烬飘散 → 地面痕迹
- 火球的膨胀速度是否合理——初始极快（爆炸瞬间），然后逐渐减速（空气阻力）
- 是否有正确的燃料耗尽过渡——火球中心从亮白/亮黄渐变到橙红再到暗黑烟雾
- 是否有冲击波视觉效果——折射变形（Shockwave Distortion）、地面尘土环形扩散
- 爆炸烟雾的上升是否形成蘑菇云形态——中心上升快、边缘卷曲回流
- 是否有放射状碎片/火花——爆炸中心向外飞溅，速度与距离成正比
- 地面爆炸和空中爆炸的行为是否不同——地面爆炸有更多尘土和碎块
- 爆炸照亮周围环境（Interactive Light）是否正确——暖色爆闪光照亮场景，亮度与距离平方反比衰减
- 是否有热变形（Heat Distortion）——爆炸高温区域空气折射扭曲
- 余烬（Embers）的飘落是否持续足够长——小碎片/火星上升后缓慢飘落
- 是否有二次爆炸——燃料未完全燃烧时可能发生二次爆燃
- 爆炸后是否留有环境痕迹——地面焦痕/弹坑/周围物体燃烧

## [艺术家自查清单 / 烟雾与云雾] 烟雾与云雾

分类: 艺术家自查清单 / 烟雾与云雾
分类ID: checklist
卡片ID: chk-atmosphere
Confluence PID: checklist
来源锚点: #chk-atmosphere

- 环境烟雾
- 烟雾的密度和厚度是否与 Plate 中的实拍元素匹配——不能比实拍烟更浓或更淡
- 烟雾的受光方向是否与场景主光源一致——Key Light 穿透烟雾的散射方向
- 是否有正确的温度分层——底部热烟上升快（稀薄），顶部冷烟扩散慢（厚重）
- 烟雾的 Turbulence 细节是否足够——多个 Octave 的 Noise，小涡旋叠加在大涡旋上
- 烟雾与场景物体的遮挡关系是否正确——Z-Depth 排序，不应穿模或错层
- 是否有环境风的影响——烟雾 drift 方向和速度应与场景中的旗帜/树叶/衣物一致
- 烟雾的颜色是否合理——燃烧烟偏灰黑/棕，雾/蒸汽偏白/灰白，魔法烟偏彩色
- 长时间镜头中烟雾的演变是否自然——不应静止，应有缓慢流动和形态变化
- 是否有 Volume 自阴影——烟雾密集区域应投射阴影到稀疏区域
- 云雾 / 云海
- 云的形态是否符合气象逻辑——积云（块状蓬松）、层云（均匀覆盖）、卷云（丝状高处）
- 云的高度是否正确——低云/中云/高云有不同的透光率和运动速度
- 是否有正确的受光——顶部受阳光（暖色高亮），底部阴影（冷色暗面），过渡自然
- 云的运动速度是否分层——近处移动快、远处慢（视差），不同高度云层速度不同
- 是否有散射光（Light Scattering）——阳光穿透云层的丁达尔效应（God Rays）
- 云的密度变化是否自然——边缘稀薄（半透明羽毛状），中心厚重（不透明）
- 相机穿云时是否有正确的体积感——进入云层时可见度逐渐降低，而非突然变白
- 云与地形的互动是否正确——山顶云环绕、山谷云海
- 时间变化下云是否演变——日出/日落时云的颜色从冷色渐变到暖色
- 远处的云是否需要简化——远距离云可用 2.5D 卡片或低精度 Volume 代替全 3D 体积

## [艺术家自查清单 / 水体与海洋] 水体与海洋

分类: 艺术家自查清单 / 水体与海洋
分类ID: checklist
卡片ID: chk-water
Confluence PID: checklist
来源锚点: #chk-water

- 海洋表面
- 海洋频谱是否正确——Wind Waves（风浪）+ Swell（涌浪）+ Chop（碎浪）是否分层叠加
- 浪高、波长、周期是否与参考/环境风力匹配——大风大浪、微风涟漪，有正确的 Beaufort 风级对应
- 是否有正确的泡沫（Foam / Whitecap）——浪尖破碎处生成白沫，被后续波浪覆盖后消散
- 是否有正确的 Spray（浪花飞溅）——浪尖被强风吹散的水雾粒子
- 海面的反射/折射是否正确——天空反射、水下折射、菲涅尔效应（远处反射强近处折射强）
- 是否有次表面散射（SSS）——浅水区/浪尖透光感，水越深透光越少
- 泡沫是否有正确的边缘——泡沫与水面交接处应有渐变透明，不能有硬边
- 大面积海洋是否有 LOD——近处高精度解算，远处用频谱叠加（Spectrum）代替全解算
- 卷浪 / 岸浪
- 卷浪的形成条件是否正确——水深变浅时波速降低、波高增加、波峰前倾直至卷曲
- 卷浪的卷曲弧度是否自然——从波峰到卷筒（Barrel）到拍岸的时间节奏是否合理
- 是否有卷浪破碎后的水流回退（Backwash）——浪冲上沙滩后退回的水流与下一波浪碰撞
- 卷曲过程中是否有薄壁透光效果——薄水壁（Lip）应该有半透明/SSS 感
- 浪破碎后的泡沫/白水扩散是否合理——沿着水流方向蔓延消散
- 是否有碎浪飞溅的二级粒子——大浪拍岸时迸溅的水滴/水雾
- 水体碰撞与交互
- 水体与碰撞体的交互是否有正确的边界层——物体边缘应有液面升高（Meniscus）效果
- 物体进入/离开水面时是否有正确的飞溅（Splash）——入水（向内凹陷+反弹水柱）、出水（水帘脱落+涟漪）
- 是否有涟漪/尾迹（Ripple / Wake）——物体在水中/水面运动时产生的 V 形尾迹
- 涟漪的衰减是否正确——近处高、远处低、随距离消散
- 是否有气泡/水下湍流——物体入水时带入的气泡、螺旋桨/尾部搅动的气泡群
- 流体粘度和表面张力是否与液体类型匹配——水（低粘度快流动）、泥浆（高粘度慢流动）
- 水体是否对水中物体有正确的浮力响应——漂浮物体应有上下颠簸（Buoyancy）
- 水下效果
- 水下是否有正确的可见度衰减——距离越远越模糊、偏蓝/偏绿（水体颜色吸收）
- 是否有水下焦散（Caustics）——水面折射光线在水底/物体表面形成的光斑图案
- 是否有 God Rays——阳光穿透水面形成的体积光束
- 是否有悬浮微粒（Particulate）——水下漂浮的微小颗粒/浮游生物增加深度感

## [艺术家自查清单 / 布料解算] 布料解算

分类: 艺术家自查清单 / 布料解算
分类ID: checklist
卡片ID: chk-cloth
Confluence PID: checklist
来源锚点: #chk-cloth

- 布料属性与设置
- 布料的物理属性是否正确——丝绸（低刚度、高光泽、细密褶皱）、棉麻（中刚度、哑光、大褶皱）、皮革（高刚度、厚实、少褶皱）
- 是否有正确的厚度——薄布料（纱/丝巾）应有半透明和双重面渲染
- 布料的各向异性（Anisotropy）是否正确——编织方向的拉伸刚度应大于斜向
- 是否有正确的 Rest Length 和 Stiffness——拉伸/压缩/剪切/弯曲 各项参数是否与布料的真实行为匹配
- 布料是否设置了正确的碰撞厚度（Thickness）——太厚会有悬浮感，太薄会穿透
- 布料动态
- 布料是否有正确重力和风力的响应——悬垂（Drape）形态、飘动幅度是否与重量匹配
- 布料的褶皱（Fold / Wrinkle）是否自然——受力支撑点向外辐射状褶皱，非均匀分布
- 是否有正确的阻尼（Damping）——布料不应无限振动，应在几次摆动后趋稳
- 布料与身体的碰撞是否准确——衣服不应穿透角色皮肤，应有滑动摩擦
- 是否有自碰撞（Self Collision）处理——布料的折叠/交叠区域不应出现穿插
- 多层布料时各层之间是否有正确的碰撞和摩擦——外层运动带动内层延迟跟随
- 特殊布料效果
- 披风/斗篷是否有正确的跟随动画——角色转身时披风应有延迟跟随（Overlap）和惯性甩动
- 旗帜飘动是否分层——旗杆附近振幅小、远端振幅大，不同部位相位不同
- 撕裂（Tear）是否有正确的断裂行为——沿编织纹理撕裂、撕裂边缘毛糙
- 湿布料效果——湿布更重（下垂更多）、颜色更深、反射增强、褶皱更细密
- 魔法布料（能量披风/光纱）——除了物理属性外是否有发光/辉光/粒子脱落
- 布料渲染
- 是否有正确的双面渲染（Double Sided）——薄布料的内外面都应可见
- 布料材质是否有正确的 Fresnel——视线与布料切线角度越小，反射越强（丝绸效果明显）
- 是否有适当的细节纹理——编织纹理（Weave Pattern）、缝线、钮扣/铆钉

## [艺术家自查清单 / 灯光与材质] 灯光与材质

分类: 艺术家自查清单 / 灯光与材质
分类ID: checklist
卡片ID: chk-lighting
Confluence PID: checklist
来源锚点: #chk-lighting

- 特效元素的受光方向是否与场景主光（Key Light）一致——检查灯光角度和强度比
- 阴影是否匹配——如果有 Shadow Matte，特效元素的阴影方向和软硬是否与 Plate 一致
- 是否添加了 Interactive Light——特效照亮周围环境（爆炸暖光/魔法彩光/刀光闪烁）
- 材质的物理属性是否正确——金属度（Metalness）、粗糙度（Roughness）、IOR、SSS
- 半透明/透明材质的深度排序是否正确——避免渲染顺序导致的穿插或闪烁
- 反射/折射 Ray Depth 是否足够——特效内部的反射/折射不应出现黑色截断
- 体积元素是否被正确的灯光影响——检查 Volume Light Contribution 和灯光 Linking
- 色彩空间一致性——所有元素在同一色彩空间下渲染和合成

## [艺术家自查清单 / 合成与最终审查] 合成与最终审查

分类: 艺术家自查清单 / 合成与最终审查
分类ID: checklist
卡片ID: chk-final
Confluence PID: checklist
来源锚点: #chk-final

- 特效元素与 Plate 的融合——黑点/白点/Gamma 匹配、Grain 叠加、Defocus 匹配
- 边缘处理——Premult/Unpremult 正确、Edge Extend（边缘延伸处理半透明边缘的暗边）
- 渲染通道检查——Deep / Cryptomatte / Motion Vector / AOV 分层是否正确
- 输出格式是否正确——色彩空间（ACEScg）、文件格式（exr）、命名规范
- 逐帧播放检查——是否有闪烁（Flickering）、跳帧（Pop）、渲染噪点异常
- 全屏和缩略图分别检查——大图看细节、缩略图看构图和大动态
- 对照原始参考做 AB 对比——至少来回切换 5 次确认无遗漏
- 是否请同事 Peer Review——至少一人独立检查后给反馈
- Nuke 工程是否清理干净——移除无用节点、注释关键处理、整理 B 面
- 交付清单是否填写完整——元素列表、已知问题、特殊说明、文件路径
- 导演/总监视角
- 这个镜头的情感表达是否到位——特效是否增强了叙事而不是分散注意力
- 在整场戏中是否连贯——和前后镜头的特效密度、风格、色彩是否一致
- 如果有疑问，是否主动找到导演/总监确认，而不是猜测意图
- Less is More——最后问自己：删掉某个元素会不会更好？
