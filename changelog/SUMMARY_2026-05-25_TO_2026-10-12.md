# Houdini-Agent 重要更新总结（2026-05-25 至 2026-10-12）

这段时间的更新可以概括为：**Houdini-Agent 从基础工具助手，逐步发展为具备执行治理、工作流 Skill、记忆系统、视觉验证和外部 MCP 扩展能力的可靠 Agent。**

## 一、6 月：建立安全执行与工具治理基础

### Harness 与安全边界

- 所有工具调用统一经过 Harness 策略检查，模型不能通过私有参数绕过确认。
- 增加输入 guardrails，拦截敏感信息、危险 Python/Shell 命令、路径穿越和非法 Houdini 节点路径。
- 工具输出统一为结构化结果，并在进入 UI、历史记录或 LLM 上下文前递归脱敏。
- 高风险操作开始按照运行模式和风险等级要求用户确认。

### 节点工具与验证增强

- 增加高频节点、场景和参数查询工具。
- 新增 `get_node_card`、`verify_network` 和 `preview_layout_nodes`。
- `create_nodes_batch` 增加预校验与 `dry_run`，减少批量操作留下半成品网络的风险。
- 清理冗余工具，Tool Registry 开始按需向模型暴露工具。
- Plan 模式改为按子系统规划，避免退化为“一节点一步”。

### 配置、规则和模型兼容性

- Rules Manager 增加原子写入、损坏文件备份、并发锁和 Token 预算保护。
- Reward Engine 修复评分问题，并记录细分分数。
- 增加 DeepSeek V4、SiliconFlow reasoning content 和 JSON Output 支持。

## 二、7 月：重点解决 Houdini 稳定性和 Manual 模式问题

### Houdini 崩溃与主线程安全

- 排查 Agent 运行期间用户操作节点造成的 Qt/Houdini 主线程竞态。
- Agent 工作期间持续显示“请勿操作 Houdini 视口/节点”的提示。
- 避免对 Volume/VDB display 节点执行危险的强制 cook，减少 GPU 重绘竞态。
- 增加生命周期安全的 Houdini 主线程执行器。
- 增加 Qt 对象存活检查、窗口隐藏后删除和空 pixmap 防护。
- 修复中文 IME 输入问题。

### Manual 更新模式治理

- 识别 Manual 模式下空几何被误诊为节点错误的问题。
- 几何查询开始返回 `manual_mode`、`is_empty_geometry`、`validation_confidence` 和 `recommended_next_action` 等结构化信号。
- Direct Execute 可以临时切换 Auto 验证，但结束后必须恢复用户原有模式。
- Confirm 模式不得擅自切换更新模式。
- 引入验证屏障，防止未完成 cook 或验证便继续执行下游步骤。

### Skill 系统形成

- 将复杂、低频工作流从核心工具迁移为 Skill，缩小核心工具表。
- 建立 Guide Skill、Workflow Blueprint Skill、帮助检索和单节点诊断 Skill。
- Skill 元数据和分类逐步标准化。
- 增加 `set_parameter_expression` 等表达式能力。
- Plan 执行强调整图优先，而不是逐节点机械调用。

### 循环检测与上下文

- 修复同一工具使用不同参数合理探索时被误判为死循环的问题。
- 提高同工具软提示阈值，并区分查询类与写入类工具提示。
- 保留总工具调用上限，避免真正的无限循环。
- 修复 Tool Call 消息配对、分页截断和自动上下文重复问题。
- 统一 Token 估算、上下文轮次规划和压缩逻辑。

## 三、8 月：完善会话、Plan 和长期记忆

### 会话与 Plan 生命周期

- 加强会话工作区恢复、历史记录和缓存可靠性。
- 修复 Plan 生命周期与执行状态不一致的问题。
- 进一步统一 Tool Registry 与 Harness 的注册、分类和治理。
- 改进插件关闭、重载和离线帮助的生命周期管理。

### 显式长期记忆

- 新增显式核心记忆，区分用户明确要求保存的内容与自动经验。
- 长期记忆写入前需要确认，避免未经授权的持久化。
- 增加人工反馈和经验奖惩机制。
- 新增记忆管理界面。
- 统一记忆数据库权威路径，并提供迁移、自动恢复和冲突处理。

### Team Memory

- 增加 Team Memory 导出文档和明确的信任边界。
- 完善个人记忆、团队记忆与运行上下文之间的隔离。
- 修复记忆工具运行时不匹配和压缩策略不一致的问题。
- 在网络盘及多副本场景中加入更保守的数据恢复策略。

## 四、9 月：加入视觉验证和外部 MCP 扩展

### 受治理的视觉审查

- 增加 Viewport Capture 基础设施，使 Agent 能够基于视口截图进行验证。
- Capture 使用独立临时目录和 Session 隔离。
- 通过 fingerprint 和保守可比性规则判断捕获结果能否比较。
- 视觉能力不可用时明确降级，不把无法验证误报为成功。
- Token 统计默认改为离线，减少隐私和外部依赖风险。

### 外部 MCP 统一治理

- 外部 MCP 工具接入统一执行入口，不再绕过 Harness。
- 增加资源限制、生命周期管理、能力清单和连接诊断。
- 新增异步 Operation 基础，支持长时间外部任务。
- Operation 状态与诊断信息更加结构化。

### Houdini 专业查询能力

新增或深化以下能力：

- SOP 几何分页查询
- USD/LOP 深度查询
- TOP/PDG 状态查询
- 受限节点写入及写后验证
- 精确参数引用查询
- 参数引用助手
- Multiparm 实例查询、插入和删除
- Object Merge 批量引用
- PDG 表达式助手

这些操作继续受到路径、参数、确认和写后验证约束。

## 五、10 月：多语言语义能力与用户 Skill 治理成熟

### 多语言 Embedding 与检索

- 引入多语言 Embedding 模型，改善中英文混合环境下的语义召回。
- 能力扩展到个人与团队记忆、知识库文档、Houdini 节点发现和 Skill 发现。
- 旧向量支持迁移和重建。
- 缓存绑定 backend、model、dimension 和格式版本；来源不兼容时不混用向量。
- 模型不可用时回退到词法检索。
- Houdini 离线资料增加 Copernicus OpenCL 内容。

### 结构化 Docs Skills

- 文档能力由通用检索发展为结构化 Docs Skills。
- 页面读取、索引和搜索共用过滤、解码及大小限制。
- 搜索结果强调可追溯的本地文档证据。
- 文档内容只用于检索和解释，不直接执行其中的代码或 Kernel。

### Skill Creator 与用户 Skill

- 增加 `draft_houdini_skill`，先生成可审查草案。
- 增加 `install_houdini_skill`，形成草案、预览、确认、安装、激活和独立测试流程。
- `preview` 严格只读；`install` 与 `activate` 必须独立确认。
- 用户 Skill 使用独立用户目录。
- 引入 `.active_skills.json` 激活清单：
  - 只有明确授权的 Skill 才能加载。
  - 新文件不会因为出现在目录中便自动执行。
  - 清单损坏时 fail closed。
  - 文件名必须与 `SKILL_INFO.name` 一致。
- 旧用户已有 Skill 会在首次升级时迁移到激活清单。

### 主线程超时治理

- Houdini 主线程操作超时后返回 `thread_still_running: true` 和 `scene_consistency: unknown`。
- 超时不再被解释为调用已经停止。
- 执行器阻断后续工具，防止与仍可能运行的操作交错。
- Executor 关闭后拒绝新调用。
- 超时、阻断、关闭和迟到结果进入受限审计，但不记录原始参数和代码。

### 审计和隐私

- `execute_python` 只记录代码 SHA-256 摘要，不记录正文。
- 外部 Operation 记录阶段、退出码、产物和单调进度。
- 诊断导出不包含 prompt、payload、绝对路径、代码正文或敏感参数。
- Team Memory 按当前用户名获取，避免用户切换后复用其他用户的 store。
- Embedding 来源不兼容时暂停语义评分，等待使用当前模型重建。

## 总体变化

| 方向 | 主要演进 |
|---|---|
| 工具执行 | 从直接调用演进为 Harness 统一治理、确认、脱敏和审计 |
| Houdini 稳定性 | 增加主线程执行器、Manual 模式处理、超时阻断和场景一致性标记 |
| Agent 工作流 | 从大量原子工具演进为核心工具与高层 Skill 分层 |
| 验证能力 | 从工具返回成功演进为网络验证、写后验证、Manual 验证屏障和视觉审查 |
| 记忆系统 | 从自动记忆演进为显式记忆、写前确认、团队隔离和模型来源校验 |
| 搜索能力 | 从词法查询演进为多语言语义检索，并支持缓存兼容性检查和降级 |
| 扩展能力 | 加入外部 MCP、异步 Operation、Docs Skills 和用户自定义 Skill |
| 安全与隐私 | 增加敏感输入拦截、结果脱敏、最小化审计、用户隔离和 fail-closed 策略 |

## 总结

**从 2026-05-25 到 2026-10-12，Houdini-Agent 的核心进步是：在扩展节点操作、文档检索、记忆、视觉验证和自定义 Skill 能力的同时，把确认、隔离、超时、审计及失败降级做成了贯穿整个执行链路的统一治理机制。**
