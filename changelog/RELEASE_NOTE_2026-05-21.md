# Houdini-Agent 精简版发布说明（2026-05-21）

## 发布摘要
本次发布聚焦于三件事：
- Harness 执行链路对齐与策略统一
- 记忆系统稳定性与长期维护能力提升
- 知识库检索质量与注入有效性提升

整体目标是让工具在复杂任务下更稳、更可控、更可追溯。

## 关键更新

### 1. Harness 与策略链路
- 引入 Harness V2 核心能力与策略决策框架。
- 高风险工具策略从多处定义收敛为单一来源。
- 执行器分类改为 Registry runtime profile 驱动，降低硬编码漂移。
- 增加策略时间线与失败恢复提示，提升可解释性。

### 2. 记忆系统
- search_memory 升级为语义/事件/策略三层联合检索。
- 统一 fallback embedding 的阈值缩放逻辑，降低误判与重复写入。
- MemoryStore 完成并发安全加固（锁、超时、busy_timeout、单例锁）。
- 新增长期维护机制：
  - 语义记忆衰减
  - 策略优先级衰减
  - 语义/策略记忆清理
  - 周期触发维护并返回统计

### 3. 知识库检索与应用
- 检索打分升级为多因子加权（标题、正文、覆盖率、来源权重、短片段惩罚）。
- 新增 query-type 重排与结果多样性约束，减少同源结果挤占。
- 自动注入改为分桶配额（node/vex/hom/knowledge），避免噪音注入。
- 低证据场景增加回退提示，优先引导精确检索。
- search_local_doc 增加结构化返回字段（source/matched_terms/rank_reason/confidence_band）。
- 缓存指纹升级为 mtime+size；无标题文档支持窗口切分。

### 4. 规则体系
- 主规则加入 karpathy-guidelines 核心行为约束，并通过现有规则注入链路自动生效。

## 兼容性与影响
- 保留 legacy 回退路径，降低切换风险。
- search_local_doc 保留原文本结果，同时新增结构化字段，兼容旧调用方式。
- 知识库缓存指纹结构升级后首次运行会触发一次缓存重建。
