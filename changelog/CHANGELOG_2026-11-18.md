# Houdini-Agent 更新记录（2026-11-18）

## 发布摘要

本次更新完善模型目录刷新、外部 MCP 治理、请求续轮与 Thinking 状态管理，并增强 Houdini 网络、PDG 和视觉结果的检查能力。

同时收紧团队记忆共享边界，补充界面状态同步与回归测试，使工具暴露、模型选择和结果验证在异常路径下保持可追踪、可恢复和默认拒绝。

---

## 一、模型目录与界面状态

- 新增 Provider 模型目录服务，保留静态模型并支持受控的远端模型列表刷新、去重、过滤和原子缓存。
- 远端目录不可用或缓存失效时回退到内置模型，不因网络故障清空已有选择。
- 模型选择界面补充刷新状态、按钮可用性和当前选项恢复，避免刷新过程覆盖用户正在使用的模型。
- 修正输入工具栏、富文本光标和偏好设置中的状态同步细节。

---

## 二、外部 MCP 治理

- 扩展外部 MCP manifest 与安全策略，明确可见工具、允许工具和风险边界。
- FastMCP 服务启用 Host/Origin 防护；运行环境不支持该能力时拒绝启动，而不是降级为不受保护的服务。
- 外部工具注册由受治理的 Tool Registry schema 驱动，只暴露显式允许且标记为外部可见的工具。
- 对执行适配器缺失、停止或不可用的情况统一 fail closed，避免可执行工具绕过主治理路径。
- 更新外部 MCP 能力漂移与参考基线 ADR，记录上游差异、采用范围和持续校验要求。

---

## 三、请求续轮与 Thinking

- 请求组装补充工具续轮所需的上下文契约，避免恢复、重试和强制总结路径丢失必要状态。
- 收紧 Thinking 开关在普通续轮、错误恢复、工具调用和停止路径中的继承规则，尊重用户显式关闭。
- 加强流式工具执行屏障，确保调用与结果按批次配对，停止或失败时不继续发送不完整续轮。
- 优化 Prompt Manager 与系统规则，明确视觉检查、工具证据和最终陈述之间的边界。

---

## 四、网络、PDG 与视觉检查

- 网络结构文本支持 Network Box 摘要：折叠盒内节点，同时保留未分组节点和结构关系，降低大型网络输出噪声。
- 增加只读 TOP/PDG 检查能力，汇总图、节点、work item、状态、属性、输出文件和调度器信息。
- PDG 表达式构造与检查结果采用受控数据路径，保持只读边界并提供可诊断错误。
- 视觉审查流程增加捕获指纹、相机视图可比性、新鲜度和模型审查契约；截图成功不再自动等同于视觉验收通过。
- 捕获失败时清理临时文件，并保留子帧等场景状态。

---

## 五、团队记忆与工具元数据

- 团队记忆导出补充来源与 embedding 元数据，重建时按当前 embedding 重新编码后再去重。
- 收紧上下文绑定规则的共享资格，保留可泛化的 Houdini 知识，避免把用户、会话或场景特定内容扩散到团队索引。
- 更新 Tool Registry 元数据与缓存记录测试，保证声明、schema、调度和外部可见性保持一致。
- 记忆激活和团队文档生成补充边界检查与回归覆盖。
